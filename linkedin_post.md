I built a real-time Data Analysis Agent as part of the Hugging Face AI Agents Course.

You ask a question in plain English. The agent fetches live data, runs the analysis, and gives you a clear answer — charts included. No SQL. No Python. No setup.

**What it pulls from:**
- Hugging Face Datasets Hub — 100,000+ real-world datasets (Spotify, Netflix, job postings, Airbnb, and more)
- Kaggle — search and load any of thousands of community datasets by keyword
- Your own CSV — upload directly in the UI

**What it can do:**
- Aggregate and rank: "Show top 10 genres by average popularity"
- Correlate: "Show correlation between all numeric columns"
- Visualise: bar, line, scatter, histogram, box, heatmap — generated on demand
- Report: structured findings with recommendations

**Model options:**
- Qwen2.5-72B via HF Inference API (free)
- Claude Sonnet 4.6 via Anthropic (plug in your API key)
- Local Ollama — auto-detected if you have it running

**What I learned from the course:**
The Think → Act → Observe loop makes agents genuinely useful — not just chatbots with a search box. A CodeAgent writes and executes Python to answer your question, so it adapts to things you didn't plan for rather than breaking.
